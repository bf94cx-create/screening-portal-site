# Screening Portal — logo assets

## Files
- assets/logo-mark.svg — primary mark (vector, transparent). Use on light grounds.
- assets/logo-mark-onDark.svg — mark for dark grounds (head/tie in paper #f3f0ea).
- assets/logo-lockup.svg — mark + wordmark + descender line.
- PNGs: logo-mark-512 / -1024 / -2048, logo-mark-onDark-1024, logo-lockup-1050 / -2100 (transparent background).

## Colours
- Gold ring: #b8892b (small gold text elsewhere: #6f5522)
- Figure torso: #2f6f9e
- Head / tie: #14293d (on dark: #f3f0ea)
- Collar highlight: #f7fbff

## Type (lockup)
- Wordmark: Barlow Condensed 600, uppercase, letter-spacing 0.04em
- Descender: Barlow 400, uppercase, letter-spacing 0.26em
Convert the lockup text to outlines before handing to print, or ship the Barlow families with the build.

## Clear space & sizing
- Clear space on all sides = radius of the ring (16 units of the 64 viewBox).
- Minimum mark size 24px; minimum lockup width 180px (below that use the mark alone).

## Don'ts
- Do not recolour the ring outside the gold ramp, rotate the mark, or place the light version on light grounds.
